# Hotel Manager — reservations view

Static implementation of the supplied Figma reservations screen. It uses plain HTML, CSS, and JavaScript with no build step or backend.

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Included interactions

- search and reservation filtering;
- room availability segments and status filters;
- removable active-filter chips;
- new reservation modal with native validation;
- reservation details modal populated from the selected row;
- responsive desktop and narrow-screen layouts.
